# Opt-in PR testing store

Once this feature has been merged and both the Pages and Cloudflare Worker deployments have succeeded, enter `https://decktation.com/testing/plugins.json` in **Decky Settings → General → Store Channel → Custom**. The listing contains the current `master` build first (if available), then one version for each **open PR with a successful, published build**. This includes fork PRs, with **no manual approval**. Versions look like `0.3.20-dev.pr-81.abcdef0`. Select the intended PR in the version dropdown before installing; Decky preselects the first available version, so check it carefully. The stable catalog at `/plugins.json` is separate and unchanged.

A PR package is served from an immutable, run-and-attempt-specific URL such as `https://decktation.com/pulls/81/123456/1/Decktation.zip`. The catalog carries a SHA-256 hash of the exact published ZIP. A new PR head requires a new successful build; closing a PR or pushing a newer head removes the earlier version from the listing. GitHub Actions for PRs run with `contents: read`, including on forks; a separate publisher running only default-branch scripts checks the live PR number, repository and head SHA before publishing. Failed/unbuilt PRs cannot appear until a package exists. Existing direct branch ZIPs remain available separately, but they are not included merely because a branch exists.

**This store deliberately offers unreviewed contributor code.** Installing a PR gives its plugin code access to your Steam Deck. A passing build, matching commit, immutable URL and checksum establish package identity, **not safety**. Inspect the PR and its dependencies before choosing it; use a disposable/test Deck if you do not trust the author. No PR is installed automatically, and automatic update discovery is disabled for this testing catalog. Switch the channel back to **Default** when finished so other plugins retain official-store update checks.

The custom URL is not live until the feature lands on `master`, the trusted workflow publishes Pages, and the Worker route is deployed. GitHub's automatically generated source archives are not installable Decktation packages.
